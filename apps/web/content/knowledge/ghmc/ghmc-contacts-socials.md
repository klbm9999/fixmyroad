Official contact details for the **Greater Hyderabad Municipal Corporation (GHMC)** for road complaints and general enquiries.

## Website and helpline

|                      |                                                    |
| -------------------- | -------------------------------------------------- |
| **Official website** | [https://www.ghmc.gov.in](https://www.ghmc.gov.in) |
| **Helpline**         | **21111111**                                       |
| **Phone**            | 040-23225397                                       |

## Address

**GHMC Head Office**  
CC Complex, Tank Bund Road, Lower Tank Bund, Hyderabad 500063

## Complaint / grievance portal

- **Online complaints**: [https://igs.ghmc.gov.in](https://igs.ghmc.gov.in) (or the current complaint/grievance URL as on [ghmc.gov.in](https://www.ghmc.gov.in)).  
  Use this to lodge road-related complaints (potholes, drainage, lights, etc.) and track status.

## Social media

- **Twitter**: [@GHMCOnline](https://twitter.com/GHMCOnline)
- **Facebook**: GHMCOnline

You can use these for general updates and, where applicable, to draw attention to issues. For formal complaint registration and tracking, use the helpline or the official complaint portal.

## Summary

- **Report a road issue**: Helpline **21111111** or the [GHMC complaint portal](https://igs.ghmc.gov.in).
- **How to lodge a complaint**: See [How to lodge a road complaint with GHMC](/knowledge/ghmc/how-to-lodge-complaint).
